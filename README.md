# ChobiKhoj BD

**ChobiKhoj BD** is a web application designed to make searching, exploring, and discovering movies around the world.

**Live Demo:** [https://chobikhojbd.vercel.app/#/](https://chobikhojbd.vercel.app/#/)

---

## Features

- **Smart Search & Discovery:** Quickly find high-quality movies and details.
- **Modern & Responsive UI:** Clean and mobile-friendly design.
- **Fast Performance:** Built with modern web technologies for quick load and smooth routing.
- **Theme Support:** Optimized viewing experience across various devices.

---

## Tech Stack

- **Frontend:** React, JavaScript, HTML5, CSS3
- **Routing:** HashRouter, React Router
- **Styling:** Tailwind
- **Deployment:** Vercel
